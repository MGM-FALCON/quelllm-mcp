quelllm-mcp

An open-source Model Context Protocol server that exposes the QuelLLM catalog of 190+ open-weights LLMs to Claude Code, Cursor, Continue, Cline, or any MCP-compatible client — so your AI assistant can answer "which local model runs on my GPU?" and "API vs self-hosted, what does it cost?".

FastMCP · Python ≥3.10 stdio transport MIT license 6 tools

What it does

The data comes live from quelllm.fr/api/ (CC BY 4.0, no key, cached locally for 1 hour). QuelLLM is a free French comparator for local, self-hostable open-weights LLMs: it tells you which model fits your VRAM/GPU, compares models head-to-head, and ranks them by use case (code, French, vision). An English edition is available at bestllmfor.com.

Tools exposed

ToolDescription
list_modelsList models with filters (origin, family, max params in B)
get_modelFull record for one model (params, VRAM per quant, context, license, URLs)
compareSide-by-side comparison of two models with a verdict
estimate_vramVRAM in GB at a chosen quantization + recommended GPU / Mac tiers
estimate_costMonthly cost in EUR — API providers vs self-hosted hardware
search_modelsFuzzy search by name, family, tag, or author

Install

Not on PyPI by design — install straight from the repository:

pip install git+https://github.com/MGM-FALCON/quelllm-mcp.git

Or run with zero install using uv:

uvx --from git+https://github.com/MGM-FALCON/quelllm-mcp.git quelllm-mcp

Use with Claude Code / Desktop / Cursor

{
  "mcpServers": {
    "quelllm": { "command": "quelllm-mcp" }
  }
}

Then ask, in natural language: "Which Mistral models run on a 12 GB GPU?" or "Compare Llama 3.3 70B vs Qwen 2.5 32B".
