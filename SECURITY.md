# Security policy

## Reporting a vulnerability

Please report suspected security vulnerabilities privately by email to **contact@quelllm.fr** with the subject **Security report — quelllm-mcp**.

Please include the affected version or commit, the steps needed to reproduce the issue, and its impact. Do not include passwords, API keys, personal data, or other secrets in the report. Please avoid public issue reports until the issue has been assessed.

This mailbox is monitored by the project maintainer. The project will acknowledge reports when possible and will assess them according to the information provided.
